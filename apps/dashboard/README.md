# SnapPick public dashboard

**Not built yet.** This folder is a placeholder for the public, no-login dashboard (Next.js) showing community recycling statistics.

The privacy-masked database views it will read already exist (small counts are suppressed): `dashboard_overview_kpis`, `dashboard_pickup_trends`, `dashboard_material_breakdown`, `dashboard_district_aggregates` and `dashboard_model_transparency`. It must use only public (`NEXT_PUBLIC_*`) values and the anon key.
